# assets/

Carpeta para los archivos multimedia de la landing page.

## Archivos esperados

| Archivo                  | Descripción                                      |
|--------------------------|--------------------------------------------------|
| `hero-photo.jpg`         | Foto profesional para la sección Hero (800×1000 px recomendado) |
| `about-photo.jpg`        | Foto para la sección Sobre mí (600×800 px recomendado) |
| `favicon.png`            | Ícono de la pestaña del navegador (32×32 px)    |
| `og-image.jpg`           | Imagen para compartir en redes sociales (1200×630 px) |

## Notas

- Formatos recomendados: `.webp` para mejor rendimiento, `.jpg` como alternativa.
- Optimizar las imágenes antes de subirlas para mejorar la velocidad de carga.
- Sustituir los placeholders SVG en `index.html` con etiquetas `<img>` una vez que las fotos estén disponibles.
